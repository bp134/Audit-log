# Project & User Preferences

## Communication Preferences (Anjum)
- **Milestone, Breakpoint & Completion Summaries:** Always provide a clear status update at the end of a project and at any natural breakpoint or pause during execution. Each update should clearly explain:
  1. **Current Position:** What has been completed and verified so far.
  2. **Next Steps:** What remains to be done or what actions are available next.
